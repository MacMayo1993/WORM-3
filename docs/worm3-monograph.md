## Abstract

WORM-3 extends the classical Rubik's cube by one mechanism: a wormhole flip repaints a fixed
antipodal pair of sticker identities by a colour involution, while moving no piece. The
implemented puzzle therefore preserves the classical positional dynamics and adjoins an
independent binary colour fibre. Under the verified identity-indexing convention, the native
move group factors as

$$M \cong G \times (\mathbb{Z}/2)^{27},$$

where $G$ is the classical cube group. This factorisation yields a complete 27-bit invariant, an
exact optimal fibre solver, and unmodified reuse of a classical positional solver on
identity-normalised facelets.

The global colour flip is itself a central element of the native move group. Quotienting by the
subgroup it generates gives a genuine quotient graph with canonical solved class
$\{(e,0),(e,\mathbf{1})\}$ and exact diameter 33 in the stated generating metric; the strict
canonical target $(e,0)$ has exact diameter 47. A separate observational target accepts the two
solved facelet strings suggested by global colour reversal and geometric antipodal viewing. Its
diameter is at most 33, but exactness is open because noncanonical internal states may alias
solved-adjacent appearances; this aliasing is not hypothetical — the minimal nontrivial alias, of
facelet support exactly four, is exhibited, proved, and now **verified against the shipped
implementation by an executable repository test** (Theorem 9, Appendix B). The central-quotient
solver is likewise implemented in full as the game's antipodal-pairs engine (Appendix C). The
mathematical tools are standard product-group and $\mathbb{F}_2$-linear methods; the contribution
is the recognition, implementation, and complete solving analysis of this specific puzzle
structure.

## 1. Classical baseline

Let $G$ denote the legal $3\times3\times3$ cube group. In cubie coordinates,

$$G = \Big\{(r,s,\sigma,\tau) \in \mathbb{Z}_3^8 \times \mathbb{Z}_2^{12} \times S_8 \times S_{12} :
\sum_i r_i \equiv 0 \ (\mathrm{mod}\ 3),\ \sum_j s_j \equiv 0 \ (\mathrm{mod}\ 2),\
\mathrm{sgn}(\sigma) = \mathrm{sgn}(\tau)\Big\}.$$

Its order is

$$|G| = 43{,}252{,}003{,}274{,}489{,}856{,}000.$$

The legal state set is a torsor under $G$, and $G$ is generated by the 18 half-turn-metric face
moves. Reachability in the larger assembly space is cut out by the corner-twist, edge-flip, and
permutation-parity constraints. The orientation subgroup is slot-referenced and enters through a
semidirect product, so orientation and permutation do not decouple.

God's Number in the half-turn metric is 20 [1]. Kociemba's two-phase algorithm supplies an
efficient nonoptimal positional solver [2]; any statement about its returned length is algorithm-
and implementation-dependent and is kept separate below from existential bounds derived from
God's Number.

## 2. Related geometric quotient puzzles

MagicTile and related constructions realise Rubik-like puzzles on quotient surfaces by identifying
edges or regions of a fundamental domain [3]. A slice-move construction can likewise impose an
antipodal geometric identification on a physical cube. Such puzzles modify the geometry and
therefore the induced move structure on slots.

WORM-3's flip layer is different. The full classical face-turn system remains intact, while an
additional operation modifies only displayed colours. WORM-3 also ships a separate geometric
"echo" mode in `src/game/antipodalMode.js`; that mode is outside the present theorem set until
its precise generators and chirality conventions are audited.

## 3. The colour-fibre model

Let $S$ be the set of 54 sticker identities. Each sticker $s \in S$ carries immutable identity
fields `orig`, `origPos`, and `origDir`, and a mutable displayed colour `curr`.

Let $\alpha$ be the antipodal colour involution

$$F \leftrightarrow B, \qquad L \leftrightarrow R, \qquad U \leftrightarrow D,$$

and let $\beta : S \to S$ be the fixed-point-free involution pairing each sticker identity with
the opposite-home-colour identity at the corresponding solved grid cell. Thus $\beta$ has 27
orbits of size 2.

For an admissible state define the identity-indexed residual

$$f \in \mathbb{F}_2^S, \qquad
f(s) = \begin{cases} 0, & \mathrm{curr}(s) = \mathrm{orig}(s), \\
1, & \mathrm{curr}(s) = \alpha(\mathrm{orig}(s)). \end{cases}$$

Write $\mathrm{wt}(f)$ for Hamming weight. The position coordinate is $g \in G$.

Three target notions will be used:

- **Strict canonical target:** the single internal state $(e, 0)$.
- **$\kappa$-target:** positions are canonical and each displayed colour is accepted modulo
  $c \sim \alpha(c)$.
- **Central quotient target:** the equivalence class $\{(e,0),(e,\mathbf{1})\}$, where
  $\mathbf{1}$ is the all-one residual.

An observational target based only on facelet strings is defined separately in Section 8.

## 4. Identity indexing and admissibility

**Lemma 1 (Identity-indexed pairing).** *The involution $\beta$ is fixed on sticker identities.
For every face-turn word $u$ and every native paired flip $\varphi_s$,*

$$u\,\varphi_s\,u^{-1} = \varphi_s$$

*as operators on residuals.*

*Proof.* By the audited implementation, $\beta$ is computed from immutable fields only. Face
turns move sticker records among slots but do not rewrite those identity fields. A paired flip
toggles the same two sticker identities wherever they currently sit. Consequently face turns act
trivially on the identity-indexed residual vector, and conjugation returns the same toggle. ∎

**Definition 1 (Admissibility).** A state is admissible when

$$\mathrm{curr}(s) \in \{\mathrm{orig}(s), \alpha(\mathrm{orig}(s))\}$$

for every $s \in S$.

This predicate is decidable in $O(54)$ time. It is stronger than checking nine stickers of each
colour: a count-balanced cross-mispaint can satisfy the colour counts while violating the
per-identity fibre condition.

**Lemma 2 (Flips move no piece).** *A native paired flip changes only the residual coordinates of
one $\beta$-pair. It changes no positional or orientation coordinate in $G$.*

**Lemma 3 (Fibre membership is invariant).** *Starting from an admissible state, face turns,
paired flips, and heals preserve admissibility.*

*Proof.* Face turns move records without altering their identity or displayed colour. The
involution $\alpha$ interchanges the two allowed colours in each identity fibre. A heal maps the
displayed colour to `orig`. Each operation therefore remains inside the two-element fibre. ∎

## 5. Phase 1: positional recovery

Define the identity-normalised facelet encoding $\rho(g, f)$ by reading each sticker's immutable
original colour rather than its displayed colour. On an admissible state, $\rho(g, f)$ is exactly
the ordinary facelet encoding of $g$.

**Theorem 1 (Phase 1 correctness).** *Let $(g, f)$ be admissible with $g \in G$. Feeding
$\rho(g, f)$ to any correct classical cube solver returns a face-turn word $u$ satisfying
$ug = e$. Executing the same word on $(g, f)$ produces $(e, f)$.*

*If the positional factor is not legal, classical validation rejects the normalised encoding
rather than returning a false solution.*

*Proof.* Normalisation removes only the colour-fibre coordinate and leaves the classical cubie
state $g$. Correctness and rejection therefore reduce to the corresponding classical solver
properties. Lemma 1 implies that the executed face turns do not alter $f$. ∎

**Theorem 2 ($\kappa$-solve).** *Phase 1 alone reaches the $\kappa$-target. Hence it is a
complete solver for the puzzle whose win condition identifies each colour with its antipode.*

*Proof.* After Phase 1 every sticker identity is home. Admissibility guarantees that its
displayed colour is either its home colour or the antipodal colour, so the two are equal in the
$\kappa$-quotient. ∎

## 6. Phase 2: the binary flip theory

A native paired flip on the orbit $[s] = \{s, \beta(s)\}$ adds

$$e_s + e_{\beta(s)}$$

to $f$. Let

$$P_\beta = \mathrm{span}_{\mathbb{F}_2}\big\{e_s + e_{\beta(s)} : [s] \in S/\beta\big\}
= \{f : f(s) = f(\beta(s)) \text{ for every } s\}.$$

Then $\dim P_\beta = 27$. Define

$$\Delta : \mathbb{F}_2^S \longrightarrow \mathbb{F}_2^{27}, \qquad
\Delta(f)[s] = f(s) + f(\beta(s)).$$

Thus $\ker\Delta = P_\beta$.

**Theorem 3 (Complete fibre invariant and optimal repair).** *For an admissible residual $f$:*

1. *Every native invertible move (face turn or paired flip) preserves the coset $f + P_\beta$.
   Equivalently, $\Delta(f)$ is invariant under the native move group.*
2. *The residual is clearable by paired flips alone if and only if $\Delta(f) = 0$.*
3. *If $\Delta(f) = 0$, the strict fibre target $0$ is reached in exactly $\mathrm{wt}(f)/2$
   paired flips. This number is optimal.*
4. *A heal can change at most one coordinate of $\Delta(f)$. The minimum number of heals required
   to enter $P_\beta$ is exactly $\mathrm{wt}(\Delta(f))$, achieved by healing the dirty sticker
   in each asymmetric pair.*

*Proof.* Face turns fix $f$ by Lemma 1, while paired flips add elements of
$P_\beta = \ker\Delta$. This proves invariance. A vector lies in $P_\beta$ exactly when it is a
sum of the disjoint pair generators, proving clearability. If $f \in P_\beta$, each dirty pair
contributes two ones and requires one flip; disjoint support proves both attainability and
optimality. Finally, every asymmetric pair must have its parity changed at least once, while
healing its unique dirty sticker resolves that pair without affecting any other pair. ∎

**Corollary 1.** *If all colour mutations in ordinary play are paired $\alpha$-flips, then
$f \in P_\beta$ throughout play and heals are unnecessary. The in-play state space is*

$$X_{\mathrm{play}} = G \times P_\beta.$$

## 7. The WAS solver

For an admissible state $(g, f)$:

1. Validate admissibility and positional legality.
2. Solve $g$ using the identity-normalised classical encoding. This reaches $(e, f)$.
3. Heal the dirty sticker in each asymmetric pair; the number of heals is exactly
   $\mathrm{wt}(\Delta(f))$.
4. Clear the resulting symmetric residual with one paired flip per dirty pair.

$$X_{\mathrm{adm}} = G \times \mathbb{F}_2^{54}
\ \xrightarrow{\ \text{classical solver}\ }\
\{e\} \times \mathbb{F}_2^{54}
\ \xrightarrow{\ \text{minimal heals}\ }\
\{e\} \times P_\beta
\ \xrightarrow{\ \text{optimal paired flips}\ }\
(e,0) \text{ or } \{(e,0),(e,\mathbf{1})\}$$

*Figure 1: The two-factor solve. Position and colour repair compose without interleaving because
the native actions commute.*

Let $L_K(g)$ denote the face-turn length returned by the chosen Kociemba backend. The implemented
solve length is

$$L_K(g) + \mathrm{wt}(\Delta(f)) + \frac{\mathrm{wt}(f^\sharp)}{2},$$

where $f^\sharp \in P_\beta$ is the residual after the minimal heals. Reported practical lengths
for a Kociemba run are empirical or backend-specific; the universal mathematical bounds below use
God's Number instead.

## 8. A correct central quotient and the observational target

Let $\gamma$ be the global colour-flip operation

$$\gamma(g, f) = (g, f + \mathbf{1}).$$

Let $H = \langle\gamma\rangle \cong \mathbb{Z}/2$.

Separately, let $\sigma(g, f)$ be the displayed facelet string and let $\bar A$ denote central
inversion acting on the slots of a facelet string. The map $\bar A$ is used only at the
appearance level unless an explicit reflection-aware internal state action is supplied.

**Lemma 4 (Solved-appearance collapse).** *For the solved facelet string $\sigma_0$,*

$$\bar A(\sigma_0) = \alpha \circ \sigma_0, \qquad \bar A(\alpha \circ \sigma_0) = \sigma_0.$$

*Hence the appearance orbit suggested by global colour reversal and antipodal viewing contains
exactly the two strings $\{\sigma_0, \alpha \circ \sigma_0\}$.*

*Proof.* Central inversion sends a solved slot on face $F$ to the corresponding slot on the
antipodal face $\alpha(F)$. The home colour at the image slot is $\alpha(c(F))$, so the
transported solved colour is the antipode of the image's home colour. Applying the colour
involution once more returns the solved string. ∎

**Lemma 5 (Global flip is internal).** *The all-one residual belongs to $P_\beta$:*

$$\mathbf{1} = \sum_{[s] \in S/\beta} \big(e_s + e_{\beta(s)}\big).$$

*Thus $\gamma$ is the product of all 27 native paired flips.*

**Lemma 6 (Central quotient).** *The subgroup $H = \{1, \gamma\}$ acts freely by graph
automorphisms on the Cayley graph of $X_{\mathrm{play}} = G \times P_\beta$. Consequently the
graph quotient $X_{\mathrm{play}}/H$ is well-defined, and the solved orbit is*

$$[(e, 0)]_H = \{(e, 0), (e, \mathbf{1})\}.$$

*Proof.* By Lemma 5, $\gamma \in M$, and $\gamma$ acts on $X_{\mathrm{play}}$ as translation by
$\mathbf{1}$ in the fibre coordinate. The native generators act as follows: a face turn sends
$(g, f) \mapsto (ug, f)$, leaving the identity-indexed residual unchanged by Lemma 1, and a
paired flip sends $(g, f) \mapsto (g, f + e_s + e_{\beta(s)})$. Translation by $\mathbf{1}$
commutes with both: it does not touch the positional coordinate, and fibre translations commute
because $P_\beta$ is abelian. Hence left multiplication by $\gamma$ maps generator-edges to
generator-edges and is a graph automorphism. Translation by the nonzero vector $\mathbf{1}$ has
no fixed point, so the action is free. The quotient and solved orbit follow. (No appeal to the
full factorisation of Theorem 6 is needed; Lemmas 1 and 5 suffice.) ∎

**Remark.** No claim is made here that geometric central inversion $A$ acts on the internally
legal cubie state space. Normalising the face-turn generator set in an ambient geometric model is
not sufficient by itself: one must also prove that the reflected solved state lies in the same
internal state space, with chirality and orientation conventions specified. The present quotient
uses only the central internal operation $\gamma$. Lemma 4 explains why the same two solved
appearances arise from the geometric motivation.

Define the observational target

$$T_{\mathrm{obs}} = \{x : \sigma(x) \in \{\sigma_0, \alpha \circ \sigma_0\}\}.$$

The canonical quotient target $\{(e,0),(e,\mathbf{1})\}$ is contained in $T_{\mathrm{obs}}$, but
equality can fail if a noncanonical internal state has one of the same facelet strings. Theorem 9
below shows that observational aliasing between pure-colour and pure-positional states is a real
phenomenon at the minimal possible facelet support, which keeps the exactness question for
observational diameters genuinely open.

## 9. Solving the central quotient

**Theorem 4 (Central quotient solver).** *Let $(g, f)$ be admissible and position-legal.*

1. *Phase 1 is unchanged and reaches $(e, f)$.*
2. *The minimum number of heals required to reach a residual from which the central quotient
   target is accessible is $\mathrm{wt}(\Delta(f))$.*
3. *After those heals, let $f^\sharp \in P_\beta$ and let $k = \mathrm{wt}(f^\sharp)/2$ be its
   number of dirty pairs. The minimum number of paired flips to reach the solved $H$-orbit is*
   $$\min(k, 27 - k).$$
   *In particular, the worst fibre cost on the in-play sector is 13.*

*Proof.* The positional phase is independent of the residual, giving item 1.

For items 2 and 3 we account per $\beta$-pair. Restricted to a single pair, the residual is one
of $(0,0)$ (clean), $(1,1)$ (symmetric dirty), or $(1,0)$ up to order (asymmetric). The available
fibre operations act on a pair as follows: a paired flip toggles both coordinates, so it maps
$(0,0) \leftrightarrow (1,1)$ and $(1,0) \leftrightarrow (0,1)$; in particular flips preserve
asymmetry. A heal sets one dirty coordinate to 0, so on an asymmetric pair it produces $(0,0)$;
heals never create a 1.

*Item 2.* Both quotient representatives $0$ and $\mathbf{1}$ restrict on every pair to a
symmetric pattern ($(0,0)$ or $(1,1)$ respectively), and paired flips preserve asymmetry. Hence
each of the $\mathrm{wt}(\Delta(f))$ asymmetric pairs must receive at least one heal before
either representative is reachable by flips, and one heal per asymmetric pair suffices, yielding
the exact count $\mathrm{wt}(\Delta(f))$.

*Item 3.* Fix the post-heal residual $f^\sharp \in P_\beta$ with $k$ dirty pairs. To reach the
representative $0$, each dirty pair needs exactly one flip and each clean pair none: cost $k$. To
reach the representative $\mathbf{1}$, each clean pair needs exactly one flip and each dirty pair
none: cost $27 - k$. Every flip changes exactly one pair coordinate between the symmetric
patterns, so these counts are lower bounds as well as attainable. The minimum over the two
representatives of the orbit is therefore $\min(k, 27-k)$, maximised at $k = 13$ or $k = 14$ with
value 13.

For completeness we record the full non-positional accounting with heals included, writing
$a = \mathrm{wt}(\Delta(f))$ for the number of asymmetric pairs and $b$ for the number of
symmetric dirty pairs. Reaching the representative $0$ costs 1 per asymmetric pair (heal) and 1
per dirty pair (flip): total $a + b$. Reaching $\mathbf{1}$ costs 2 per asymmetric pair (a heal
to $(0,0)$ followed by a flip to $(1,1)$; a flip alone leaves the pair asymmetric and a heal
alone cannot produce a 1) and 1 per clean pair: total $2a + (27 - a - b) = a + (27 - b)$. The
minimum non-positional cost to the quotient target is thus $a + \min(b, 27 - b)$, in agreement
with items 2 and 3. ∎

This solver is implemented verbatim as `planQuotientCompletion` / `applyQuotientCompletion` in
the antipodal-pairs engine; Appendix C reproduces the source and records one engine-level
refinement (the flip-cap guard) that the idealised group model does not see.

## 10. Implementation audit

The mathematical conclusions that depend on the implementation rest on three repository-wide
claims, each now discharged at the pinned commit of Section 17:

1. **Identity immutability.** The fields `orig`, `origPos`, and `origDir` are written only
   during construction and by-value copying. Rotation, undo, scramble, and serialization paths
   do not rebase them.
2. **Colour-mutation coherence.** Outside tests, every writer of `curr` is either a heal or an
   $\alpha$-flip applied to a $\beta$-pair.
3. **Pairing convention** *(new in revision 5; formerly the conditional hypothesis of
   Theorem 9)*. `findAntipodalStickerByGrid` (`src/game/manifoldLogic.js`) pairs each sticker
   identity with the same-index grid cell on the antipodal face, and the induced convention on
   the $UD$-layer edge stickers is **central inversion**: the $U$-sticker of the $UF$ slot pairs
   with the $D$-sticker of the $DB$ slot, and the $U$-sticker of the $UB$ slot with the
   $D$-sticker of the $DF$ slot. This is verified by the executable check of Appendix B, now a
   repository test (`src/__tests__/antipodalEngine.test.js`, suite "Theorem 9 observational
   aliasing"), which asserts the partner locations directly and compares all 54 displayed
   facelets of the flip state against the classical double-swap state.

Claims 1 and 2 imply admissibility invariance and $\Delta \equiv 0$ in ordinary play; claim 3
makes Theorem 9 unconditional.

**Win-detection semantics** (resolving former Open Problem 4). At the pinned commit,
`checkRubiksSolved` (`src/game/winDetection.js`) implements the *observational strict target*: it
accepts exactly the states whose displayed facelet string is $\sigma_0$ (each slot shows its
face's home colour; identities are not consulted). `checkRubiksSolvedAntipodal` implements the
per-facelet $\kappa$-quotient (each slot's displayed colour lies in its face's antipodal class),
which is weaker than $T_{\mathrm{obs}}$: it accepts mixed strings that are neither $\sigma_0$ nor
$\alpha \circ \sigma_0$. The engine's `isFibreInSolvedOrbit` implements the fibre component of
the canonical quotient orbit ($f \in \{0, \mathbf{1}\}$), which combined with a positional check
realises the internal central-quotient target of Section 8.

## 11. Comparative results

**Theorem 5 (Conservativity).** *On a flip-free state $(g, 0)$, the WORM-3 solver coincides
exactly with the classical solver: normalisation changes nothing, Phase 1 is the classical solve,
and Phase 2 is empty.*

**Theorem 6 (Exact factorisation).** *The native move group is*

$$M = G \times P_\beta \cong G \times (\mathbb{Z}/2)^{27}.$$

*Face-turn words have zero fibre effect, paired-flip words have zero positional effect, and the
two actions commute. Distances to product targets therefore add.*

*Proof.* Lemma 2 gives one direction of independence and Lemma 1 the other. The 27 pair
generators have disjoint supports and are independent, so their subgroup is
$P_\beta \cong (\mathbb{Z}/2)^{27}$. The intersection of the two factors is trivial. ∎

**Theorem 7 (Universal solvability, precisely stated).** *Let $(g, f)$ be admissible and
position-legal, and let $f^\sharp$ be the residual after the unique minimal heal on every
asymmetric pair.*

1. *Under the move system augmented by heals, the exact minimum non-positional cost to reach the
   strict canonical target is*
   $$\mathrm{wt}(\Delta(f)) + \frac{\mathrm{wt}(f^\sharp)}{2}.$$
   *The total minimum is*
   $$d_G(g, e) + \mathrm{wt}(\Delta(f)) + \frac{\mathrm{wt}(f^\sharp)}{2}.$$
2. *The exact minimum to reach the central quotient target is*
   $$d_G(g, e) + \mathrm{wt}(\Delta(f)) + \min(k, 27 - k), \qquad k = \frac{\mathrm{wt}(f^\sharp)}{2}.$$
3. *Write $a = \mathrm{wt}(\Delta(f))$ for the number of asymmetric pairs and
   $b = \mathrm{wt}(f^\sharp)/2$ for the number of symmetric dirty pairs. Since $a + b \le 27$,
   every admissible position-legal state has both a strict solution and a central-quotient
   solution of length at most 47. These mixed-move bounds are exact over the full admissible
   state space. On the in-play sector $a = 0$, the strict bound remains 47 while the
   central-quotient bound improves to 33.*

*Proof.* The positional and fibre operations act on independent coordinates. Theorem 3 gives the
exact strict fibre cost, and Theorem 4 gives the exact quotient fibre cost. Each $\beta$-pair is
either asymmetric, symmetric dirty, or symmetric clean, so $a + b \le 27$. The quotient cost is
no larger than the strict cost because $\min(b, 27-b) \le b$. Adding $d_G(g, e) \le 20$ gives 47.
Exactness over the admissible state space is attained by a distance-20 classical state together
with 27 asymmetric pairs, each of which requires at least one heal. On the in-play sector
$a = 0$, Theorem 4 gives the sharper quotient maximum $20 + 13 = 33$. ∎

**Lemma 7 (Symmetric flips preserve colour counts).** *A paired flip applied to a
$\beta$-symmetric pair preserves all six global colour counts. Hence every state reachable from
the standard initial state using face turns and paired flips retains nine stickers of each
colour.*

*Proof.* For a symmetric pair, the displayed colours are $\{c, \alpha(c)\}$ both before and after
the flip, with the two instances exchanged. By contrast, on an asymmetric pair $(1, 0)$, both
displayed stickers change from $\alpha(c)$ to $c$, so the unrestricted statement would be
false. ∎

**Theorem 8 (Observational novelty).** *A single paired flip applied to the solved state changes
exactly two facelets. No nontrivial legal classical cube state differs from the solved facelet
string in only one or two positions. Therefore the appearance of one WORM-3 flip lies outside the
classical cube orbit.*

*Proof.* The paired flip changes its two selected sticker identities. For a classical state, an
orientation defect cannot occur on a single cubie: the edge-flip and corner-twist sums force
additional defects, producing at least four changed facelets. If all cubies are correctly
oriented but the permutation is nontrivial, then either an even permutation moves at least three
cubies, or matched odd edge and corner permutations move at least four cubies. A displaced cubie
has a different colour set from its destination and therefore changes at least one facelet. Thus
a nontrivial legal classical state changes at least three facelets. The lower bound is sharp: a
three-cycle of three edges sharing one face colour can change exactly three side facelets. ∎

**Theorem 9 (Minimal observational aliasing — unconditional as of revision 5).** *Under the
verified pairing convention of Section 10, the $U$-sticker of the $UF$ slot and the $D$-sticker
of the $DB$ slot form one $\beta$-pair, and the $U$-sticker of the $UB$ slot and the $D$-sticker
of the $DF$ slot form another. Flipping these two $\beta$-pairs on the solved state produces
exactly the same facelet string as the legal classical double swap*

$$UF \leftrightarrow DF, \qquad UB \leftrightarrow DB,$$

*with all four edges unflipped. In the Kociemba facelet convention this common string is*

```
UDUUUUUDU RRRRRRRRR FFFFFFFFF DUDDDDDUD LLLLLLLLL BBBBBBBBB
```

*which differs from the solved string in exactly the four facelets $U2, U8, D2, D8$. By
Theorem 8, facelet support four is the minimum possible for a nontrivial alias between a pure
paired-flip appearance and a pure classical appearance, and this example attains it.*

*Proof.* The full 54-entry computation is carried out in Appendix B and executed against the
shipped implementation by the repository test cited there; we summarise its three steps.

*The flip state.* Each paired flip repaints its two sticker identities by $\alpha$ and moves
nothing. Under the verified convention, the pair through $U$-of-$UF$ repaints $U8$
($U \mapsto D$) and $D8$ ($D \mapsto U$), and the pair through $U$-of-$UB$ repaints $U2$
($U \mapsto D$) and $D2$ ($D \mapsto U$). All other 50 facelets are unchanged, so the affected
set is exactly $\{U2, U8, D2, D8\}$.

*The classical state.* The cubie assignment with identity corner permutation, edge permutation
$(UF\ DF)(UB\ DB)$, and all orientation coordinates zero satisfies every reachability constraint
of Section 1: the twist and flip sums vanish, and both permutations are even, so their signs
agree. By the constraint description of $G$, this state is legal. With edge orientation zero,
each of the four $UD$-layer edges displays its $U/D$-type sticker on the $U$ or $D$ face. Hence
the $UF$ slot, occupied by the $DF$ edge, shows $D$ on $U8$ and $F$ on $F2$; the $DF$ slot shows
$U$ on $D2$ and $F$ on $F8$; the $UB$ slot shows $D$ on $U2$ and $B$ on $B2$; the $DB$ slot shows
$U$ on $D8$ and $B$ on $B8$. The $F$- and $B$-facelet exchanges swap equal colours, so the
visible support is exactly $\{U2, U8, D2, D8\}$ with the same values as the flip state.

*Comparison.* The two 54-entry strings coincide entry by entry (Appendix B tabulates all 54 and
records the executable check). Minimality of the support follows from Theorem 8: a nontrivial
classical appearance has facelet support at least three, and a pure paired-flip residual has even
support, excluding supports two and three; support four is therefore minimal and is attained
here. ∎

Note that the flip state and the classical state assign the four repainted facelets to
*different* $\beta$-pairs / edge cycles — the flip pairs run through central inversion while the
witnessing double swap runs through the equator mirror — yet the two appearances coincide,
because both repaint the same four facelets by $\alpha$. This is precisely why appearance-level
reasoning cannot distinguish the two internal states.

**Corollary 2 (The observational intersection is nontrivial).** *The intersection*

$$\{\sigma(e, f) : f \in P_\beta\} \cap \{\sigma(g, 0) : g \in G\}$$

*contains a string other than $\sigma_0$. Consequently observational win conditions genuinely
identify distinct internal states, and exact observational diameters cannot be inferred from the
canonical distances of Section 13 without analysing this intersection.*

## 12. Structural algebra

The classical orientation data is slot-coupled, producing a twisted extension. WORM-3's native
colour fibre is identity-indexed, producing the split central extension

$$1 \longrightarrow (\mathbb{Z}/2)^{27} \longrightarrow M \longrightarrow G \longrightarrow 1,
\qquad M \cong G \times (\mathbb{Z}/2)^{27}.$$

The classical reachability invariants are augmented by the 27 coordinates of $\Delta$.
Algebraically,

$$\mathbb{F}_2^{54}/P_\beta \cong \mathbb{F}_2^{27}.$$

Using the standard facts $Z(G) \cong \mathbb{Z}/2$ and $G^{\mathrm{ab}} \cong \mathbb{Z}/2$,

$$Z(M) \cong (\mathbb{Z}/2)^{28}, \qquad M^{\mathrm{ab}} \cong (\mathbb{Z}/2)^{28}, \qquad
[M, M] = [G, G] \times \{0\}.$$

**Proposition 1.** *The maximum element order in $M$ is 1260.*

*Proof.* The known order spectrum of the classical cube group has maximum 1260 and maximum odd
order 495 [5]. For $(g, v) \in G \times (\mathbb{Z}/2)^{27}$,

$$\mathrm{ord}(g, v) = \mathrm{lcm}(\mathrm{ord}(g), \mathrm{ord}(v)), \qquad
\mathrm{ord}(v) \in \{1, 2\}.$$

If $\mathrm{ord}(g)$ is even, adjoining $v$ does not increase it. If it is odd, the result is at
most $2 \cdot 495 = 990$. Since order 1260 already occurs in $G$, it remains the maximum in
$M$. ∎

## 13. Exact canonical distances and observational bounds

Use the generating set consisting of the 18 HTM face turns and the 27 paired flips; heals are
excluded. The Cayley graph is the Cartesian product of the classical graph and a 27-cube, so for
$f \in P_\beta$,

$$d_M\big((g, f), (e, 0)\big) = d_G(g, e) + \frac{\mathrm{wt}(f)}{2}.$$

**Theorem 10 (Canonical God's Number).** *The maximum distance to the strict internal target
$(e, 0)$ is exactly*

$$20 + 27 = 47.$$

*It is attained by combining a classical distance-20 position with the all-one residual.*

**Theorem 11 (Central-quotient diameter).** *The maximum distance in $X_{\mathrm{play}}/H$ to the
solved orbit $[(e, 0)]_H$ is exactly*

$$20 + \max_{0 \le k \le 27} \min(k, 27 - k) = 20 + 13 = 33.$$

*Proof.* For a state with $k$ dirty pairs, the distance to the solved orbit is
$d_G(g, e) + \min(k, 27 - k)$. The two factors are independent, and a distance-20 classical state
can be combined with any fibre residual. The maximum of the second term is 13. ∎

**Theorem 12 (Observational target bounds).** *Every in-play state can be brought to
$T_{\mathrm{obs}}$ in at most 33 moves. Every in-play state can be brought to the solved facelet
string $\sigma_0$ in at most 47 moves.*

*Neither bound is asserted to be exact for the corresponding observational target. By
Corollary 2, additional internal states are known to share facelet appearances across the two
factors, so the worst-case observational solutions may genuinely be shorter than the canonical
distances.*

*Proof.* The central quotient target $\{(e,0),(e,\mathbf{1})\}$ is a subset of
$T_{\mathrm{obs}}$, giving the 33-move bound. The canonical strict target $(e, 0)$ displays
$\sigma_0$, giving the 47-move bound. ∎

Determining the exact observational diameters is a joint distance problem over the intersection

$$\{\sigma(e, f) : f \in P_\beta\} \cap \{\sigma(g, 0) : g \in G\},$$

which Theorem 9 shows to be nontrivial. Characterising this intersection is necessary input; it
does not by itself guarantee that the worst-case diameter drops below the canonical bound.

## 14. Group versus monoid

The native in-play system is a group action. A heal is a noninvertible idempotent projection, so
adjoining heals produces a transformation monoid. The invariant $\Delta$ is preserved by the
group and deliberately broken by the monoid. Consequently native solvability is a coset
condition, while heal-augmented solvability is graded by the exact cost $\mathrm{wt}(\Delta(f))$.

## 15. A sufficient solver-reuse criterion

**Sufficient solver-reuse criterion.** *Let $X = B \times F$, with:*

1. *base and fibre moves acting on separate factors;*
2. *the base acting trivially on an identity-indexed fibre;*
3. *$F$ abelian and fibre moves given by translations by a subgroup $K \le F$;*
4. *a decidable admissibility condition identifying valid fibre descriptions.*

*Then any complete base solver applies unchanged to the normalised base coordinate; the complete
fibre invariant is the quotient class in $F/K$; targets that are unions of $K$-cosets alter only
the final cost calculation; and base and fibre phases compose without interleaving.*

*Proof.* The reachable fibre set from $f$ is exactly $f + K$, so $F/K$ is the universal coset
invariant. Trivial base action on the fibre makes normalisation and phase composition exact. A
target that is a union of $K$-cosets is detected entirely in $F/K$. ∎

The criterion is sufficient, not necessary. Twisted extensions can still admit reusable solvers
through equivariant or specially chosen coordinates. Its diagnostic value is narrower: identity
indexing is what turns the WORM-3 fibre into a closed-form arithmetic problem rather than a
search problem.

## 18. Conclusion

WORM-3 adjoins an identity-indexed central binary fibre to the classical cube while preserving
the entire classical positional move system. The resulting native group is the direct product

$$G \times (\mathbb{Z}/2)^{27},$$

so positional search and colour repair are exact complements. The classical factor is solved on
identity-normalised facelets; the fibre factor is solved by the complete invariant $\Delta$ and
disjoint-pair arithmetic. This yields exact canonical distances 47 and 33 for the strict target
and the central quotient, respectively — and, as of revision 5, both solvers exist as running
code: the strict planner and the central-quotient planner are implemented, tested, and driven
visually in the game's Three.js scene (Appendix C).

The geometric antipodal intuition survives at the observational level: central inversion of the
solved appearance and global colour reversal produce the same two facelet strings. What does not
follow without further work is an internal action of geometric inversion on the legal cubie state
space. Keeping that distinction explicit leaves a clean theorem set. The genuinely open problem
is now sharply posed: observational aliasing between the two factors is proved to exist at the
minimal facelet support of four (Theorem 9, verified in-repo), and what remains is to
characterise the full aliasing intersection and to determine how much it can shorten solutions
when the win condition sees only facelets.

## Appendix B. The 54-entry facelet computation for Theorem 9

### Conventions

Facelets are listed in the Kociemba order $U1 \ldots U9$, $R1 \ldots R9$, $F1 \ldots F9$,
$D1 \ldots D9$, $L1 \ldots L9$, $B1 \ldots B9$. The $U$ face is read with the $B$ face at the top
row, so $U2$ is the $U$-facelet of the $UB$ slot and $U8$ is the $U$-facelet of the $UF$ slot.
The $D$ face is read with the $F$ face at the top row, so $D2$ is the $D$-facelet of the $DF$
slot and $D8$ is the $D$-facelet of the $DB$ slot. Edge orientation follows the standard
convention in which a $UD$-layer edge has orientation 0 exactly when its $U/D$-type sticker lies
on the $U$ or $D$ face.

### State A: two paired flips on the solved state

Under the verified grid-cell convention (Section 10) the two flipped $\beta$-pairs are

$$\{\,U\text{-sticker of } UF,\ D\text{-sticker of } DB\,\} \quad\text{and}\quad
\{\,U\text{-sticker of } UB,\ D\text{-sticker of } DF\,\}.$$

A paired flip repaints both stickers of its pair by $\alpha$ and moves nothing. Starting from the
solved string, the affected facelets are

$$U8 : U \mapsto D, \qquad D8 : D \mapsto U, \qquad U2 : U \mapsto D, \qquad D2 : D \mapsto U,$$

and no other facelet changes. (Under the equator-mirror convention considered in revision 4 the
pair-to-facelet assignment permutes $D2$ and $D8$ between the two pairs, but the *union* of
affected facelets — and hence the two-pair flip string — is identical.)

### State B: the legal double swap

Take the cubie assignment with identity corner permutation, edge permutation
$(UF\ DF)(UB\ DB)$, and all corner-twist and edge-flip coordinates zero. Checking the constraints
of Section 1: the twist sum is $0 \bmod 3$; the flip sum is $0 \bmod 2$; the corner permutation
is the identity (even) and the edge permutation is a product of two transpositions (even), so
$\mathrm{sgn}(\sigma) = \mathrm{sgn}(\tau)$. Hence the state lies in $G$.

With orientation zero, each of the four displaced $UD$-layer edges shows its $U/D$-type sticker
on the $U$ or $D$ face and its $F/B$-type sticker on the $F$ or $B$ face. Reading off slot by
slot:

| Slot | Occupant | $U/D$ facelet | shows | $F/B$ facelet | shows |
|---|---|---|---|---|---|
| $UF$ | $DF$ | $U8$ | $D$ | $F2$ | $F$ |
| $DF$ | $UF$ | $D2$ | $U$ | $F8$ | $F$ |
| $UB$ | $DB$ | $U2$ | $D$ | $B2$ | $B$ |
| $DB$ | $UB$ | $D8$ | $U$ | $B8$ | $B$ |

The $F$- and $B$-facelet entries coincide with the home colours of their slots, so the visible
support is exactly $\{U2, U8, D2, D8\}$.

### C.2 The quotient planner

The planner is a direct transcription of the per-pair accounting in the proof of Theorem 4:

```javascript
export function planQuotientCompletion(cubies, size) {
  const pairs = enumerateBetaPairs(cubies, size);
  const P = pairs.length;

  const asymmetric = pairs.filter((p) => p.kind === 'asymmetric');
  const dirty = pairs.filter((p) => p.kind === 'dirty');
  const k = dirty.length;

  // Mandatory heals: the dirty member of each asymmetric pair.
  const heals = asymmetric.map((p) => (p.dirtyA ? p.a : p.b));

  // Pairs each representative would flip (post-heal, asymmetric pairs are clean).
  const towardZero = dirty;
  const towardOne = pairs.filter((p) => p.kind !== 'dirty');
  const oneFeasible = towardOne.every((p) => p.flippable);

  const target = oneFeasible && P - k < k ? 1 : 0;

  const flips = [];
  if (target === 1) {
    for (const p of towardOne) flips.push(p.a);
  } else {
    for (const p of towardZero) {
      if (p.flippable) flips.push(p.a);
      else heals.push(p.a, p.b); // dead pair: native flip impossible, heal both
    }
  }

  return {
    target,
    heals,
    flips,
    healCost: heals.length,
    flipCost: flips.length,
    totalCost: heals.length + flips.length,
  };
}
```

On the in-play sector ($a = 0$, no dead tiles) this reduces exactly to Theorem 4: $k$ flips
toward $0$, or $27 - k$ flips toward $\mathbf{1}$, whichever is smaller, with ties broken toward
the strict representative.

### C.3 An engine-level refinement: the flip cap

The idealised model of Sections 6–9 treats every paired flip as always available. The game
additionally imposes a *flip cap*: a sticker that has been flipped `FLIP_CAP` times becomes
"dead" and no native flip can touch it (heals still can, and reset the count). The engine
accounts for this outside the theorem set: a pair containing a dead sticker is marked
non-flippable; under target $0$ a dead dirty pair falls back to two heals; and target
$\mathbf{1}$ is selected only when every pair it must flip is flippable. On any state in which no
sticker has reached the cap, the engine's costs coincide with the exact values of Theorems 4
and 7; the cap only ever adds heals, never invalidates the invariant theory, since $\Delta$ and
$P_\beta$ are defined on residuals alone.
